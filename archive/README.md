# Historical comparison inputs

These seven files are exact Git blobs copied from the commits already used by
`paper/build_tables.py`: four superseded April main-run files for the wording
ablation, and three tool-enabled request CSVs. `sources.json` records each source
commit/path, Git blob ID and SHA-256. The cached reproduction gate verifies both
hashes. Retaining the files here makes a source ZIP or shallow checkout sufficient;
no historical records are pooled into the retained main panel.

These are historical comparisons, not newly collected responses. The manifest
counts the current `results/` runs and failures separately from these snapshots.
